# Material fornecido

Diferente de `transcricao/` (o que foi dito na aula) e `resumo/` (a síntese por tema) — aqui entra o **material que o professor forneceu junto** com a aula: slides, PDF, planilha, swipe file, o que for. Não é gerado por transcrição; é colado por você.

Organizado por tema, com os mesmos códigos de `resumo/` (`copy`, `criativos`, `facebook-ads`, `google-ads`, `metricas`, `gestao-de-trafego`). Dentro de cada tema, nomeie o arquivo com a mesma referência de data/professor da aula, pra rastrear de qual aula veio:

```
material-fornecido/<tema>/<data-ou-sem-data>-<professor>-<descrição>.<ext>
```

Exemplo: `material-fornecido/copy/2026-08-17-bifi+amanda-planilha-headlines.xlsx`
