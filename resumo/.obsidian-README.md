# Leia antes de editar — cofre Obsidian dos resumos

Esta pasta `resumo/` foi feita para ser aberta **como um cofre (vault) do Obsidian**.
No Obsidian: *Open folder as vault* → selecione esta pasta `resumo/`.

Cada arquivo de tema (`copy.md`, `criativos.md`, ...) tem duas camadas:

1. **SÍNTESE CONSOLIDADA (topo)** — entre os marcadores
   `<!-- ===== SÍNTESE CONSOLIDADA ... -->`. **NÃO edite à mão.** Ela é
   **regravada por inteiro** toda vez que você roda `/resumir`. Qualquer texto seu
   digitado aí será **perdido** na próxima execução.

2. **REGISTRO POR AULA (abaixo)** — blocos `## <data> — <título> · <professores>`.
   São **append-only**: o `/resumir` só acrescenta blocos novos, nunca reescreve os
   antigos. Não edite blocos de aula à mão (perde a fidelidade à transcrição).

## Onde colocar as SUAS anotações

Você tem duas opções seguras, ambas preservadas pelo `/resumir`:

- **Notas separadas:** crie outros arquivos `.md` no cofre (ex.: `ideias-copy.md`) e
  use wikilinks `[[copy]]` para referenciar os temas. Arquivos novos nunca são tocados.
- **Seção própria no fim do arquivo de tema:** adicione, ao **final** do arquivo, uma
  seção começando exatamente com o título:

  ```markdown
  ## Minhas anotações
  (o que você escrever aqui é preservado entre execuções)
  ```

  O `/resumir` **preserva** qualquer seção `## Minhas anotações` ao regravar a síntese.

## Resumindo o que NÃO editar
- ❌ A síntese consolidada no topo (regravada a cada execução).
- ❌ Os blocos de aula (append-only, fidelidade à transcrição).
- ✅ Arquivos seus separados, e a seção `## Minhas anotações`.

> Nota: os arquivos de índice/controle (`_indice.md`) e este README também não devem
> ser editados à mão — são gerados/mantidos pelo pipeline.
