# Este arquivo é lido por processar.py para montar a "dica" (campo prompt) que
# vai ao Whisper. O prompt da API aceita só ~224 tokens; por isso o script NÃO
# manda o arquivo inteiro: ele prioriza os nomes próprios (professores) e os
# termos mais propensos a erro, usa o NOME DO ARQUIVO de áudio como sinal de
# tema para escolher quais entram, e corta o resto quando estoura o orçamento.
#
# SINTAXE (não precisa decorar — só seguir o padrão ao editar):
#   - Linhas começando com # são comentários e são ignoradas.
#   - [SECAO] abre uma seção.
#   - Em [VOCABULARIO], cada linha é:  temas => termo, termo, termo
#       temas = palavras-chave (separadas por espaço). Se alguma aparecer no
#               nome do arquivo de áudio, a linha ganha prioridade.
#               Use  *  para "sempre relevante" (siglas e termos universais).
#   - Em [PROFESSORES], um nome por linha. Nomes próprios entram SEMPRE primeiro,
#       porque são o que o Whisper mais erra e o que mais contamina o resumo.
#
# Ordem de prioridade que o script aplica ao preencher o orçamento de tokens:
#   1) professores  ->  2) linhas cujo tema bate com o nome do arquivo
#   ->  3) linhas marcadas com *  ->  4) o restante, até o limite.
