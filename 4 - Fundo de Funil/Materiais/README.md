# Materiais — 4 - Fundo de Funil

Material que o professor forneceu junto com as aulas desta Estratégia: slides, PDF,
planilha, swipe file. Não é gerado por transcrição; é colado manualmente (Mac ou Dell).

Nomeie com a mesma referência de data/professor da aula, para rastrear a origem:

```
{data-ou-sem-data}-{professor}-{descrição}.{ext}
```

Depois de adicionar arquivos aqui pelo Dell, rode `/sync-material` para subir pro
GitHub num passo só.
