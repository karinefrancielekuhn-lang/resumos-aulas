# Material fornecido — Copywriting

Diferente de `Resumos/` (a síntese das aulas) — aqui entra o **material que o
professor forneceu junto**: slides, PDF, planilha, swipe file. Não é gerado por
transcrição; é colado manualmente.

Nomeie o arquivo com a mesma referência de data/professor da aula, para rastrear
de qual aula veio, quando souber:

```
{data-ou-sem-data}-{professor}-{descrição}.{ext}
```
